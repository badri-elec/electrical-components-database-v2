# Electrical Components Database v2

A simple Python application for managing electrical components using Object-Oriented Programming (OOP).

This project is the second version of my previous Electrical Components Database project.

Compared to the first version, this release introduces:

- Object-Oriented Programming
- Inheritance
- JSON Save/Load
- Search Components
- Input Validation
- Better Code Organization
- Interactive Menu

The purpose of this project was to practice Python fundamentals while building a small real-world console application.

## Features

- Add Resistors
- Add Capacitors
- Add Inductors
- Display Components
- Save Data to JSON
- Load Data from JSON
- Search Components by Name
- Input Validation

## Concepts Practiced

- Classes and Objects
- Inheritance
- Functions
- Lists
- Dictionaries
- JSON
- File Handling
- Exception Handling
- Object-Oriented Programming

## Version

This is Version 2 of the project.

The first version was created as a beginner practice project.
Version 2 refactors the project using OOP and adds several new features.
